# 活动别报亏：电商保本价计算器

给小商家在报名促销、发券或投放前做单笔利润和保本价估算。直接打开 `index.html` 即可使用，无需安装、账号、API Key 或联网；输入只在当前浏览器页面处理。

## 当前功能

- 按用户提供的买家实付、补贴、商品成本、优惠、履约成本、费率和其他成本计算估算利润。
- 显示估算利润率和满足条件时的保本售价。
- 缺失项保持提示，不读取或猜测平台费率。
- 费率基数目前固定为买家实付；若平台实际基数不同，请勿直接套用结果。
- 不保存数据、不连接店铺、不自动改价或报名活动。

## 使用方法

1. 下载本仓库，双击 `index.html` 用浏览器打开。
2. 替换演示数据为你核实过的金额和费率。
3. 核对平台费用的计费基数、优惠由谁承担、补贴能否结算，以及是否存在未填成本。
4. 用结果决定是否需要进一步人工复核，不把估算当成到账金额。

## 计算口径

```text
确认收入 = 买家实付 + 已确认可结算的平台补贴
估算单笔利润 = 确认收入 - 商品成本 - 商家优惠（尚未体现在实付中时）
             - 履约成本 - 其他单笔成本 - 买家实付 × 费率合计
估算利润率 = 估算单笔利润 ÷ 确认收入
保本售价 = 固定单笔成本 ÷ (1 - 比例费率合计)
```

保本售价公式仅适用于页面所用费率都按售价计费、固定成本和费率完整、没有计入补贴且费率合计低于 100% 的情况。费率基数不同、数据缺失或优惠重复计算时，结果可能不适用；存在空项时页面只显示已知项小计，不反推保本售价。

## 项目边界

这是经营估算小工具，不是平台费率数据库、会计报表或税务建议。所有输入由使用者提供；下单前应以商家后台和当期平台规则复核。请勿在公开 Issue 中粘贴订单号、客户信息或未脱敏账单。

## 变现试验（尚未验证）

GitHub 上的普通仓库不会因为发布就自动产生收入。先用免费计算器收集真实使用反馈；如果用户明确需要，再制作按平台/类目拆分的可维护模板、团队版批量表格或定制服务。先验证愿付费意向，再开发收费版本。不要把本仓库的试用数写成收入或市场证明。
