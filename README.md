# 活动别报亏：电商活动决策实验室

一个无需账号、无需安装、可离线运行的电商促销决策工具。一次比较最多 6 个售价/补贴/销量方案，查看单笔贡献利润、保本售价、覆盖活动固定投入所需订单数和预计活动净额。所有输入保存在当前浏览器，不发送到服务器。

## 在线使用

打开 [电商活动决策实验室](https://liuq88450-del.github.io/ecommerce-break-even-calculator/)。也可以下载仓库后直接打开 `index.html`。

## 它解决什么

单个“利润计算器”只能回答一个价格下的结果。本工具把活动决策拆成三层：

1. **共用成本**：商品、履约、其他单笔成本、费率和活动固定投入只填一次。
2. **方案实验**：并列填写售价、商家优惠、确认补贴、预估订单量和单笔广告投放。
3. **经营结果**：比较每单贡献、利润率、保本价、保本订单量和按预估销量计算的活动净额。

支持本地自动保存、CSV 导出、载入演示方案和清除本机草稿。最多比较 6 个方案。无需联网即可计算。

## 计算口径

```text
费率合计 = 平台及支付费率 + 达人/分销佣金率
单笔贡献 = 买家实付 + 已确认补贴 - 商品成本 - 履约成本 - 其他单笔成本
           - 尚未计入买家实付的商家优惠 - 买家实付 × 费率合计 - 单笔投放
保本售价 = max(0, (商品成本 + 履约成本 + 其他单笔成本 + 商家优惠 + 单笔投放 - 补贴) ÷ (1 - 费率合计))
保本订单 = 向上取整(活动固定投入 ÷ 单笔贡献)，仅当单笔贡献大于 0
预计活动净额 = 单笔贡献 × 预估订单数 - 活动固定投入
```

这里的“贡献”和“净额”是输入假设下的经营估算，不是会计净利润或平台结算承诺。工具假设比例费率都按买家实付计收；如果平台以其他金额为基数，需要先核实再使用。未知成本或费率必须核实，不能当作 0。优惠如果已体现在买家实付中，不要再次扣除；补贴只有符合结算条件时才填入。

## 安全与隐私

- 不接店铺、不调用 API、不上传成本或商品数据。
- 自动保存只写入当前浏览器的本地存储；导出的 CSV 由用户主动保存。
- 不包含第三方脚本、广告、远程字体或分析追踪代码。
- 换设备或清除浏览器数据后，本地草稿不会自动同步。清除按钮会删除当前浏览器保存的草稿。

## 变现验证

公开仓库和 GitHub Pages 不会按浏览量自动付费。目前没有将访问、下载或星标转化为收入的机制。先邀请真实小商家用同一款商品比较日常价、活动价和投流方案，记录是否完成决策、哪里不清楚、是否愿意保存模板或付费。只有出现明确的重复使用或真实付费意向，才开发进阶产品。

## 项目边界

仅用于活动前测算和学习，不给出“保证赚钱”的结论，不自动改价/报名，不替代平台当期规则、会计或税务核对。请勿在公开 Issue 粘贴客户姓名、电话、地址、订单号或未脱敏账单。

## 本地开发

项目为纯 HTML/CSS/JavaScript 单页，不依赖构建工具或外部 CDN。直接打开 `index.html` 即可。
